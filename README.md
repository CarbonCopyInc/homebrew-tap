# Hoplite Homebrew Tap

Official Homebrew tap for the [Hoplite](https://hoplite.sh) CLI.

## Install

```sh
brew install CarbonCopyInc/tap/hoplite
```

## Upgrade

```sh
brew upgrade hoplite
```

Formulae in this tap are published automatically by Hoplite's CLI release
pipeline. Archives are downloaded from https://hoplite.sh/downloads and
verified against per-release SHA-256 checksums.
